# Quote evidence checklist

| Dimension | Capture | If absent |
| --- | --- | --- |
| Scope | Aircraft or seat; one-way/return; airports/dates | Do not compare as equivalent |
| Schedule | Local windows, stops, deadline fit | Pending confirmation |
| Aircraft | Model and offered configuration | Not a guaranteed aircraft |
| Party needs | Pax, baggage, pets, accessibility | Capacity alone is insufficient |
| Provider | Broker and named operating carrier | Do not assume the same entity |
| Price | Currency, total, inclusions, expiry | Estimate or incomplete price |
| Extras | Documented fees/exclusions | Unknown, not zero |
| Cancellation | Penalties, deadlines, refunds, charter changes | Ask; do not infer |
| Recovery | Substitutions, delays, backup obligations | No assumed guarantee |
| Booking | Offer, hold, contract, payment, reference | Quote/inquiry only |

Mark findings documented, independently verified, missing, or conflicts with trip. Attribute source/date. Keep private quotes within the requested comparison; do not republish or upload them elsewhere without authorization.

The Private Jet Specialist public booking page is an estimate/request flow through Villiers. It does not reserve aircraft or take payment at the estimate step. Reinspect current behavior rather than hardcoding submission endpoints.
